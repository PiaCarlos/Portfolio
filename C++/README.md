# C++ Projects Portfolio

This portfolio showcases C++ projects focused on command-line applications, object-oriented programming, memory management, and problem-solving.

---

# Contact Manager (C++)

A command-line contact management system written in C++ that allows users to store, search, update, delete, and analyze contact information.

## Features

- Add new contacts
- Display all saved contacts
- Search contacts by name
- Update a contact's phone number
- Update a contact's phone number and email
- Delete contacts
- Count contacts by email domain
- Display contact statistics
- Uses structs, arrays, pointers, recursion, and function overloading

👉 [Project Repository](https://github.com/PiaCarlos/C-Contact-Manager)

# Project Manager (C++)

A command-line project management system written in C++ that manages projects, team members, tasks, task assignments, and task status.

## Features

- Create and manage projects
- Add team members with roles and task limits
- Create tasks with descriptions, priorities, and statuses
- Assign tasks to team members
- Prevent members from exceeding their task limit
- Display projects, team members, and assigned tasks
- Search projects and team members by ID
- Filter tasks by status
- Demonstrates object-oriented programming and dynamic memory management

👉 [Project Repository](https://github.com/PiaCarlos/C-Project-Manager/blob/main/project_Manager.cpp)

# Advanced Project Manager (C++)

An expanded project management system written in C++ that builds on the previous project by adding inheritance, polymorphism, specialized project types, specialized task types, budgets, and exception handling.

## Features

- Manage multiple projects
- Support software projects and research projects
- Add team members with roles and task limits
- Create different task types:
  - Development tasks
  - Testing tasks
  - Documentation tasks
- Assign tasks to team members
- Track project budgets
- Display projects, teams, and assigned tasks
- Filter tasks by status
- Handle invalid operations with custom exceptions
- Demonstrates inheritance, polymorphism, abstract classes, virtual functions, and dynamic memory allocation

👉 [Project Repository](https://github.com/PiaCarlos/C-Advanced-Project-Manager)
