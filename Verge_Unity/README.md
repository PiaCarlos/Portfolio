# Shattered Worlds: Verge

GitHub repository: https://github.com/The-ScrumCycle/CRPGProject

Shattered Worlds: Verge is a Unity/C# isometric CRPG developed by an 8-person team.  
The game combines multi-island exploration, ship travel, NPC dialogue, companions, enemy encounters, save/load progression, and tactical turn-based combat.

## My Role

I worked as the team leader and world/exploration lead.  
I created the Unity repository, helped define the scope of the game, organized the team into world, combat, and dialogue groups, coordinated weekly progress, helped integrate the different systems, managed merges before demos, and prepared the final build.

## My Main Contributions

- Designed the overall world structure and island layout
- Created the movement system for world exploration
- Built the exploration gameplay around moving, interacting, traveling, and triggering encounters
- Connected the islands into a playable open-world structure
- Created and fixed the ship travel system between islands
- Added enemy encounters across the islands
- Connected world enemies to specific combat scenarios
- Implemented transitions from exploration to combat
- Implemented the return flow from combat back to exploration
- Added death and game over transitions
- Added load-save functionality during gameplay and from the game over screen
- Fixed save/load issues during development
- Added the companion system and connected companions to gameplay
- Worked on monster AI and encounter behavior
- Added dialogue for NPCs, companions, story progression, and the final boss
- Handled final merging, build testing, and final build preparation

## Game Features

- Multi-island pirate-inspired open world
- Click-to-move exploration
- Ship travel between islands
- NPC dialogue and story progression
- Companion characters
- Enemy encounters across the world
- Tactical turn-based combat
- Complex combat with multiple enemies and multiple companions
- Different combat scenarios connected to exploration encounters
- Monster AI and enemy behavior
- Final boss encounter with Malakor
- Save/load system using JSON save data
- Game over screen with load-save functionality
- Scene transitions between exploration, combat, death, and game over
